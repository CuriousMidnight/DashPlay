THREE SIMPLE STEPS
01

Open any stream format

Paste a direct link to any .m3u8 (HLS), .mpd (MPEG-DASH), .flv, .mp4, or .mkv stream.

02

Add headers or Protection

Save per-site request headers for streams that return 403 errors, or enter a license URL, headers, and robustness level for protected DASH streams.

03

Share with friends

Click Copy shareable link. Your stream URL, format, per-site headers, and Protection settings are encoded into a single link ready to open.

i

Good to know

Use HTTPS links when hosted on GitHub Pages. External video hosts must allow cross-origin playback (CORS) and any custom request headers you configure. Protected streams require an EME-compatible browser under HTTPS or localhost.
